# ⚡ Asynchronous Programming in JavaScript — Complete Guide & Lab

A hands-on, practical repository exploring the mechanics of **asynchronous JavaScript**, the V8 Event Loop, Microtask vs Macrotask queues, Promises, Async/Await, and concurrency primitives.

---

## 📚 Topics Covered
1. **The Event Loop & Call Stack**: Call stack execution order, Web APIs, Task Queue vs Microtask Queue.
2. **Callbacks & Callback Hell**: Understanding inversion of control and pyramiding asynchronous logic.
3. **Promise Architecture**:
   - Promise states (`pending`, `fulfilled`, `rejected`).
   - Promise chaining, error handling with `.catch()` and `.finally()`.
   - Combinators: `Promise.all()`, `Promise.allSettled()`, `Promise.race()`, `Promise.any()`.
4. **Async / Await**: Syntactic sugar over generators & promises, sequential vs concurrent execution, error boundaries with `try/catch`.
5. **Real-world Async Patterns**: Rate limiting, retry mechanisms with exponential backoff, and debouncing.
